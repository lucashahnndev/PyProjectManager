================================================================================ 
DEPENDENCY MANAGER - MODO PIP (dependency_manager_pip.bat)
Este script e um modulo de servico para gerir ambientes virtuais e dependencias
atraves do pip. Nao e projetado para uso direto pelo utilizador.

MODOS DE OPERACAO

--ensure-env
Modo "smart". Garante que o ambiente virtual existe e que as dependencias
estao instaladas, com base na flag --deps-installed. Cria o venv e/ou
instala as dependencias apenas se for necessario.

--shell
Abre um novo terminal (CMD) com o ambiente virtual ativado e pronto a usar.
Cria o venv e instala as dependencias na primeira vez.

--add-dep <pacote>
Instala um novo pacote no ambiente virtual e adiciona-o ao ficheiro de
dependencias, se especificado.

--remove-dep <pacote>
Desinstala um pacote do ambiente virtual e remove-o do ficheiro de
dependencias, se especificado.

--rebuild
Forca a reconstrucao completa do ambiente virtual e a reinstalacao de todas
as dependencias.

--help, -h
Mostra esta tela de ajuda.

PARAMETROS

--python-exe <caminho>
Obrigatorio. Especifica o caminho completo para o python.exe.

--project-dir <caminho>
Obrigatorio. Especifica o diretorio raiz do projeto.

--venv <caminho>
Opcional. Especifica o caminho para a pasta do ambiente virtual.

--deps-file <caminho>
Opcional. Especifica o caminho para o ficheiro de dependencias.

--deps-installed <True|False>
Usado pelo modo --ensure-env para decidir se as dependencias precisam
de ser instaladas.

--no-cache
Opcional. Usado com --rebuild ou na instalacao para forcar o pip a
ignorar o seu cache de pacotes.
