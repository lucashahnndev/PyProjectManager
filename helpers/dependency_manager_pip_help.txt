================================================================================ 
DEPENDENCY MANAGER - MODO PIP (dependency_manager_pip.bat)
Este script e um modulo de servico para gerir ambientes virtuais e dependencias
atraves do pip. Nao e projetado para uso direto pelo utilizador.

MODOS DE OPERACAO

--shell
Abre um novo terminal (CMD) com o ambiente virtual ativado e pronto a usar.
Opcionalmente, instala as dependencias na primeira criacao do venv.

--add-dep <pacote>
Instala um novo pacote no ambiente virtual e adiciona-o ao ficheiro de
dependencias, se especificado.

--remove-dep <pacote>
Desinstala um pacote do ambiente virtual e remove-o do ficheiro de
dependencias, se especificado.

--rebuild
Apaga completamente o ambiente virtual e os caches (.pyc), e depois recria
o ambiente e reinstala as dependencias do zero.

--help, -h
Mostra esta tela de ajuda.

PARAMETROS OBRIGATORIOS (para todos os modos)

--python-exe, --py <caminho>
Especifica o caminho completo para o python.exe que sera
usado para criar e gerir o ambiente virtual.

--project-dir <caminho>
Especifica o diretorio raiz do projeto onde as operacoes serao executadas.

PARAMETROS OPCIONAIS

--venv <nome_pasta>
Especifica o nome da pasta do ambiente virtual (ex: "venv").
Se nao for fornecido, o script nao tentara criar ou ativar um venv.

--deps-file <caminho_ficheiro>
Especifica o caminho para o ficheiro de dependencias (ex:
"requirements.txt"). Usado para instalar pacotes na criacao do venv.

--no-cache
Usado com --rebuild, forca a limpeza do cache do pip antes de reinstalar
as dependencias, garantindo um download limpo de todos os pacotes.
